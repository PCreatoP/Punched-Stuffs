## 📖 About the Modpack

**Punched Stuffs** is a lightweight, fully optimized Vanilla+ modpack designed to make your Minecraft world feel alive. It includes **70+ carefully selected mods and resource packs**, combining the power of **Fresh Animations** and punchy movements. Every mob, player action, and environment detail becomes incredibly smooth and dynamic — all while keeping the classic Mojang art style and delivering maximum performance.

## 🚀 How to Install

The easiest way to play is using **Prism Launcher** or **PineconeMC**:

1. Download and open [Prism Launcher](https://prismlauncher.org) or [PineconeMC](https://pineconemc.com).
2. Download our **.mrpack** (or **.zip**) file from the links above.
3. In your launcher, click **"Add Instance"** (or "Create Profile").
4. Select **"Import from file"** and choose the downloaded modpack file.
5. Launch the game and enjoy!
