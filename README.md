## 📖 About the Modpack

**Punched Stuffs** is a lightweight, fully optimized Vanilla+ modpack designed to make your Minecraft world feel alive. It includes **70+ carefully selected mods and resource packs**, combining the power of **Fresh Animations** and punchy movements. Every mob, player action, and environment detail becomes incredibly smooth and dynamic — all while keeping the classic Mojang art style and delivering maximum performance.

## ✨ Features

*   🎬 **Alive World** — Fully integrated Fresh Animations for expressive and cinematic mob behaviors.
*   💥 **Punchy & Responsive** — Enhanced player combat and movement animations that feel satisfying.
*   📦 **70+ Mods & Resource Packs** — A perfect, pre-configured mix of visual improvements and essential mods.
*   ⚡ **Insanely Optimized** — Built on Fabric with top-tier optimization mods for a stutter-free experience and high FPS.

## 🚀 How to Install

The easiest way to play is using **Prism Launcher** or **PineconeMC**:

1. Download and open [Prism Launcher](https://prismlauncher.org) or [PineconeMC](https://pineconemc.com).
2. Download our **.mrpack** (or **.zip**) file from the links above.
3. In your launcher, click **"Add Instance"** (or "Create Profile").
4. Select **"Import from file"** and choose the downloaded modpack file.
5. Launch the game and enjoy!

## 🐞 IMPORTANT READ IT

If you happened to open the "Resource Packs" menu, some animations or held items might not display correctly. To fix this, press the **Win + R** keys, type `%appdata%`, and press **Enter**. Then, select your launcher from the list of folders, go to the `instances` folder, and select the folder named "Punched Stuffs" (or whatever you named it). Next, navigate to the `minecraft` folder, find the `config` folder, and look for the `punchy` folder inside it. Locate the `punchy_config.json` file, delete it, and then restart the game.

</details>
